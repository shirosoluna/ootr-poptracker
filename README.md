# Ocarina of Time Randomizer (Console)

This pack was created to support the console OoT randomizer. It currently has the following features available:

All Logic Rules (Glitchless, Advanced, No Logic-All Checks accessible)
Vanilla and MQ Dungeons
Updated Maps with 3D layouts or Overworld Only
Autotracking (WIP)
Entrance Randomizer (WIP)

## Installation

Just download the latest build ofrom releases and put in your packs folder (unpacked).
